# Laundry App — Digital Order

Project dummy full-stack: React + Vite + TS + Tailwind (frontend),
Node.js + Express (backend), Supabase (database + auth + RLS),
AI chat agent (Claude API).

## Setup

1. Jalankan `database/schema.sql` di Supabase SQL Editor, lalu `database/rls_policies.sql`.
2. `cd backend && cp .env.example .env` — isi dengan API key asli, lalu `npm install && npm run dev`.
3. `cd frontend && cp .env.example .env` — isi dengan API key asli, lalu `npm install && npm run dev`.

Penjelasan detail tiap baris kode ada di file `PANDUAN-LAUNDRY-APP.md` yang terpisah.
